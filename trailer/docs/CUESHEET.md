# 《완벽한 불청객》 트레일러 — 큐시트 (타이밍 기준표)

영상 30fps, 총 길이 **97.0초**. 모든 시각 단위는 초(트레일러 타임라인 기준, 0 = 첫 프레임).
영상 편집은 이 그리드에 맞춰 컷한다. 음악은 이 표를 "정답"으로 삼아 정확히 맞춘다.

## 템포 그리드
- S1 왈츠: 3/4, ♩=120 → 1박 0.5s, 1마디 1.5s. 시작 0.60s.
- S3 이후 전부: 4/4, ♩=120 → 1박 0.5s, 1마디 2.0s. 마디 1 시작 = 16.10s.
  (4/4 마디 n의 다운비트 = 16.10 + (n-1)*2.0)
