# 완벽한 불청객 (The Perfect Uninvited Guest)

> 파티에 초대받지 못했다고? 괜찮아. 황금 오리만 가져가면 되니까. 🦆

*Untitled Goose Game* 풍의 파스텔 3D 그래픽으로 만든, *Hitman* 식 샌드박스 잠입 코미디 게임입니다.
초대받지 못한 불청객이 되어 오덕수 회장의 저택 파티에 숨어들고, 전시실의 **황금 오리**를 훔쳐 빠져나오세요.
정해진 정답은 없습니다. 몰래 숨어들 수도 있고, 변장해서 섞일 수도 있고, 전기를 끊거나 약을 타서 기회를 만들 수도 있고, 불꽃놀이와 화재 경보로 아수라장을 만들 수도 있습니다.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173 에서 플레이
npm run build      # dist/ 에 정적 빌드 (아무 정적 호스팅에 올리면 됨)
npm test           # 시뮬레이션 테스트 (아래 참고)
```

키보드로 플레이하는 데스크톱 브라우저 게임입니다. 소리는 모두 Web Audio로 실시간 합성됩니다(헤드폰 권장).

## 무엇이 들어 있나

### 살아 있는 저택 하나
- 연회장, 라운지 바, 식당, 주방, 직원 휴게실, 보안실, 전기실, 회장 서재, 전시실, 온실, 뒤뜰 정원, 선착장, 서비스 마당 등 **20여 개 구역**.
- 손님 11명, 직원 11명, 경비 8명, 회장 1명 — **31명**이 각자의 일과를 산다. 웨이터는 음료를 나르고, 주방장은 요리하다 담배 피우러 나가고, 메이드는 방을 돌며 청소하고 쓰레기를 내다 버리고, 보안실 근무자는 모니터를 보다 커피를 마시러 간다.
- 회장의 **연설**, 손님들을 데리고 가는 **전시실 투어**, 피날레 **불꽃놀이** 같은 이벤트가 시간에 따라 벌어진다.

### 보고 들은 것만 아는 사람들
- 모든 인물은 **시야(방향·거리·조명·벽·닫힌 문)** 와 **청각(소리 크기·벽 너머 감쇠)** 으로만 세상을 안다.
- 수상한 장면을 본 손님/직원은 **가장 가까운 경비에게 달려가 신고**하고, 경비는 **무전**으로 동료들에게 옷차림을 퍼뜨린다. 무전이 없는 손님은 모른다.
- 의심 → 경고/제지 → 추격 → 수색 → 경계 상태로 복귀. 아무도 못 봤다면 아무도 모른다.
- 정문 경비와 집사는 초대 명단을, 주방장은 주방 식구를, 보안실장은 부하들을 알아본다(변장 간파).

### 서로 연결된 시스템
- **전기**: 두꺼비집의 본관/서비스동/보안 차단기. 끄면 조명이 꺼져 시야가 줄고, 카메라·모니터·진열장 경보가 멈춘다. 대신 경비들은 손전등을 켜고, 보안실 근무자는 무전을 치고, 전기기사가 고치러 오고, 보안실장은 직접 오리를 지키러 간다. 전기기사 열쇠를 훔치면 집사나 실장이 대신 온다.
- **감시카메라**: 보안실 근무자가 지켜보고 있을 때만 실시간으로 반응한다. 아무도 안 보면 **녹화**만 되고, 봉쇄 후 녹화 기록이 검토되면 찍힌 옷차림이 수배된다. 보안 콘솔에서 기록을 지울 수 있다.
- **문과 열쇠**: 잠긴 문, 자물쇠 따기, 소매치기한 열쇠, 다시 잠그는 NPC, 열린 채 방치된 전시실 문을 수상히 여기는 경비.
- **음료와 약**: 커피·정수기·펀치에 수면제나 설사약. 마신 사람만 효과를 본다(잠든 사람은 의자에서 졸거나 바닥에 쓰러지고, 발견되면 소동이 된다).
- **소음**: 휘파람, 던진 병, 깨진 꽃병, 주크박스, 불꽃놀이, 화재 경보 — 누가 들었는지에 따라 다른 사람이 반응한다.
- **물건**: 선물 상자·은쟁반에 오리 숨기기, 쓰레기통에 숨긴 물건이 메이드에 의해 대형 쓰레기통으로 옮겨지기, 밖에 떨어진 오리를 경비가 주워 보안실에 보관하기, 고무 오리 + 금색 페인트 = 가짜 황금 오리(무게 센서 속이기, 투어 때 회장이 알아챌 수도).

### 여러 갈래의 공략
- 들어가는 길: 초대장(소매치기·차 뒤지기) / 울타리 개구멍 / 고장 난 욕실 창문 / 쪽문 경비의 흡연 시간.
- 오리를 얻는 길: 전시실 열쇠(보안실장·회장) / 서재 비밀문(서재 열쇠·자물쇠 따기) / 회장 투어에 끼기 / 정전 / 경보 해제 / 바꿔치기 / 대놓고 들고 뛰기.
- 나가는 길: 정문, 직원용 쪽문, 울타리 개구멍, 선착장 보트, 배달 밴.
- 결과 화면에서 발각 횟수, 수배된 옷, 도난 발각 여부, 남은 녹화 기록 등으로 칭호(최고: **완벽한 불청객**)를 받는다.

## 코드 구조

```
src/
  sim/            게임 시뮬레이션 (렌더링과 무관, node에서 테스트)
    Grid.ts         1m 격자, 벽/문/창문 엣지, 시야(LOS), A* 경로, 충돌
    World.ts        모든 시스템과 엔티티를 소유하는 루트
    npc/            인물: 지각(perception), 두뇌(brain), 행동(behaviors), 일과(routine)
    Security.ts     무전망, 감시카메라, 녹화, 경보, 봉쇄
    Lighting.ts     전기 회로와 조명 지도(시야 판정과 렌더링이 같은 값을 씀)
    Director.ts     연설/투어/불꽃놀이/화재 경보 이벤트
    interactions.ts 플레이어가 할 수 있는 모든 행동
    level/          저택 배치, 인물·일과·소문·대사 콘텐츠
  view/           three.js 렌더링 (단면 절단 벽, 캐릭터, 시야 원뿔, 파티클)
  ui/             HUD, 말풍선, 미니맵, 수첩, 메뉴 화면
  audio/          Web Audio 실시간 합성 효과음·목소리·적응형 피아노 음악
tests/            지도 검증, 시스템 시나리오, 도달 가능성, 15분 소크 테스트, 전문가 봇 플레이스루
```

## 테스트

시뮬레이션은 렌더링과 분리되어 있어 node에서 그대로 돌아갑니다.

- `map.test.ts` — 문이 실제 벽 위에 있는지, 모든 지점이 막히지 않았는지, 시야/경로 판정.
- `scenarios.test.ts` — 차단기를 내리면 카메라·경보가 꺼지고 전기기사가 고치러 오는지, 커피에 탄 수면제, 목격자의 신고와 무전 전파, 빈 진열장 발견 → 봉쇄, 가짜 오리를 투어 때 회장이 알아채는지, 옷을 갈아입으면 추격이 끊기는지 등 17가지 상황.
- `reachability.test.ts` — 모든 상호작용 지점에 실제로 다가가 쓸 수 있는지, 개구멍·욕실 창문·문을 실제 이동으로 통과할 수 있는지.
- `probes.test.ts` — 정식 손님은 파티장에서 의심받지 않고, 손님 차림으로 주방을 돌아다니면 지적받는지.
- `soak.test.ts` — 아무 개입 없이 15분 동안 파티가 오류 없이 굴러가고 모두가 움직이는지.
- `bot.test.ts` — 실제 입력으로 움직이며 "아무도 안 볼 때만" 행동하는 봇이 개구멍 → 욕실 창문 → 고무 오리·창고 페인트 → 서재 비밀문 → 바꿔치기 → 선물 상자 → 보트로 **들키지 않고 탈출**하는지.
